# Smilux Web Client

Frontend application for **Smilux** — Dental Practice Management System.

A proprietary healthcare platform developed and owned by **[Tekvora Systems](https://tekvora.co.ke/)**.

Built with **React 19**, **Vite**, **Tailwind CSS**, and **React Router v7**.

## Quick Start

```bash
# Install dependencies
pnpm install

# Start development server
pnpm dev

# Build for production
pnpm build

# Run linting
pnpm lint
```

For full system architecture, backend setup, database seeding, and ownership details, refer to the root [README.md](../README.md).
