# Smilux API Server

Backend REST API for **Smilux** — Dental Practice Management System.

A proprietary healthcare platform developed and owned by **[Tekvora Systems](https://tekvora.co.ke/)**.

Built with **Node.js**, **Express**, **MongoDB (Mongoose)**, and **JWT**.

## Quick Start

```bash
# Configure environment
cp .env.example .env

# Install dependencies
pnpm install

# Seed sample database
node seed.js

# Start development server
pnpm dev

# Run linting
pnpm lint
```

For full system architecture, frontend setup, seed accounts, and API route overview, refer to the root [README.md](../README.md).
